# teloxide-router-macros

Procedural macros for [`teloxide-router`](https://github.com/YouKnow-sys/teloxide-router).

This crate is not intended to be used directly. Depend on `teloxide-router` instead, which re-exports all macros from this crate:

```toml
[dependencies]
teloxide-router = { git = "https://github.com/YouKnow-sys/teloxide-router" }
```
